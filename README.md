# 嘉盛物料映射工具

用于维护“嘉盛物料映射汇总表”的本地 Excel 批处理工具。

当前提供两个核心功能：

1. **导入客户物料清单**：批量读取客户 Excel，将物料整理、去重后写入主映射汇总表。
2. **合并外部映射汇总表**：将其他人员维护过的映射汇总表安全合并回主表，并对冲突数据进行人工确认。

工具以 Python + Excel 文件方式运行，不需要数据库。日常使用通过根目录的 `启动工具.bat` 完成。

## 使用前准备

### 1. Python 环境

电脑需要安装 Python。

`启动工具.bat` 默认使用 Windows Python Launcher：

```text
py
```

BAT 会自动检查 `openpyxl` 和 `xlrd`。缺少依赖时会尝试通过 `pip` 安装。

### 2. 主映射汇总表

主表固定放在：

```text
data/嘉盛物料映射汇总表.xlsx
```

如果使用的是旧版本文件：

```text
03-嘉盛物料映射汇总表.xlsx
```

请将其改名为：

```text
嘉盛物料映射汇总表.xlsx
```

并移动到 `data` 目录。

### 3. 运行

双击：

```text
启动工具.bat
```

菜单：

```text
[1] 导入客户物料清单
[2] 合并外部映射汇总表
[Q] 退出
```

# 功能 1：导入客户物料清单

将客户 Excel 放入：

```text
data/客户清单/待处理/
```

然后运行：

```text
[1] 导入客户物料清单
```

成功处理的文件移动到：

```text
data/客户清单/已处理/
```

异常文件移动到：

```text
data/客户清单/异常/
```

处理日志：

```text
logs/customer_import.log
```

## 当前客户表读取规则

处理两个 Sheet：

- `电柜元器件`
- `电柜半成品`

当前统一输出结构为 7 列业务数据。

主要规则：

- 以 **D 列为空**作为当前数据结束条件。
- **B 列物料号存在时，优先按 B 去重。**
- B 列为空时仍然提取，不会因为没有物料号而丢弃。
- **B 为空时按 D 与已有数据去重。**
- 新数据 B 已有物料号，但主表按 B 找不到时，可通过配置开启“按 D 回填历史空 B 记录”。
- D 唯一匹配到历史 B 为空记录时，只补写原行的 B 列，不改人工映射区。
- D 存在多条候选记录时不自动猜测，避免误覆盖。

## 人工映射区保护

当前人工维护的映射区域从 **M 列开始**。

脚本追加客户物料时不会主动覆盖已有人工映射关系。

修改已有主汇总表之前，会先在：

```text
backup/
```

生成完整备份。

# 功能 2：合并外部映射汇总表

将其他人员维护过的映射汇总表放入：

```text
data/映射合并/待合并/
```

运行：

```text
[2] 合并外部映射汇总表
```

成功处理的来源文件移动到：

```text
data/映射合并/已合并/
```

日志：

```text
logs/mapping_merge.log
```

## 匹配原则

合并时采用：

```text
B列物料号 → 主匹配字段
D列       → 辅助/备用匹配字段
```

主要流程：

```text
B有物料号
    ↓
先按B查找
    ↓
找到 → 比较人工映射
    ↓
找不到 → 再检查D
    ↓
无冲突 → 新增
有歧义 → 用户决定
```

B 为空时按 D 匹配。

## 映射合并原则

人工映射区为：

```text
M:V
```

安全规则：

- 主表映射为空、来源表有值：可以自动补齐。
- 来源表为空、主表已有值：**不会用空值清除主表内容**。
- 双方都有值但内容不同：视为冲突。
- “覆盖”默认只覆盖 `M:V`，不会覆盖 `A:L` 基础数据。
- 主表 B 为空、来源表 B 有正式物料号且可以安全匹配时，允许补写 B。

## 冲突处理

出现异常或冲突时可以选择：

```text
[O]  覆盖映射
[A]  新增为一行
[S]  跳过
[Q]  取消本次全部合并

[OA] 后续冲突全部覆盖
[AA] 后续冲突全部新增
[SA] 后续冲突全部跳过
```

其中：

- `O`：只覆盖允许修改的映射区域。
- `A`：保留原记录，同时将来源记录新增为一行。
- `S`：不处理当前冲突。
- `Q`：取消本次合并，**主汇总表不保存本次修改，来源文件也不移动**。

保存主表之前会自动备份。

# 数据安全原则

本工具当前遵循以下原则：

1. 主汇总表是长期维护的数据文件，不应被重新生成覆盖。
2. 人工维护的映射关系优先保护。
3. 修改已有主表前自动备份。
4. 能确定的数据自动处理。
5. 存在歧义的数据交给用户决定。
6. 不使用来源表空值清除主表现有人工映射。
7. 合并过程中选择取消时，不保存本次主表修改。
