# 嘉盛物料映射工具 v1.4.2

## 版本定位

v1.4.0 改为“项目目录驱动”。项目文件夹不再放入工具 `data` 目录，也不需要把同一批电气清单在多个“待处理”目录之间重复复制。

> v1.4.2 在 v1.4.1 基础上调整脚本4 ERP BOM 规则：`京能物料号=客供件` 的记录不进入ERP；同一母件下相同子件自动合并数量，并在合并后重新连续编号。

工具目录只保存程序、全局映射数据、ERP模板、全局映射备份和脚本2的全局日志；项目原始资料与项目输出都留在项目自己的文件夹中。

## 启动

双击：

```text
run_tool.bat
```

菜单：

```text
1 - 导入客户物料清单（选择项目文件夹）
2 - 合并外部映射汇总表（全局映射维护）
3 - 生成客户清单京能物料对应表（选择项目文件夹）
4 - 生成 ERP 物料清单批量导入表（选择项目文件夹）
5 - 项目一键处理：1 -> 3 -> 4（推荐）
Q - 退出
```

菜单1、3、4、5选择后会弹出 Windows 文件夹选择窗口。项目目录可以位于桌面、文档盘、网络盘等任意位置，不要求位于工具目录中。

## 脚本1：导入客户物料清单

扫描所选项目目录及其子目录中的 Excel 电气清单，排除：

- `项目\输出\` 下的所有文件；
- `物料导入*.xls`；
- 名称类似 `01-...嘉盛-导入.xlsx` 的无意义导入文件。

处理固定 Sheet：

- `电柜元器件`：第4行开始，D列为空结束；
- `电柜半成品`：第3行开始，D列为空结束。

主映射表：`data\嘉盛物料映射汇总表.xlsx`。

映射区域统一为 M:X，共6组：M:N、O:P、Q:R、S:T、U:V、W:X。

发现新物料时写入主映射表并自动备份原主映射表。项目原始文件不移动。

## 脚本2：合并外部映射汇总表

脚本2仍属于全局映射维护，不依赖项目目录。其输入、处理方式保持原有安全合并逻辑，主映射区域为 M:X。

## 脚本3：生成京能物料对应表

直接读取所选项目目录中的原始电气清单，输出到：

```text
项目\输出\物料回填\
```

输出文件包含原电气清单回填列 AA:AC，并生成统一 Sheet：`京能物料对应汇总`。

汇总列：来源Sheet、原始行号、客户物料号、品名、型号、品牌、规格、客户数量、京能物料号、京能数量、匹配状态、物料来源。

公共物料来自主映射表 `公共物料` Sheet，并使用同一 M:X 映射区域。

脚本3只要存在未匹配、冲突、数量异常、映射数量异常、未配置京能物料或公共物料异常，就视为“不能继续自动生成ERP”。

## 脚本4：生成 ERP 物料清单批量导入表

所选项目根目录需要且只能有一个：

```text
物料导入*.xls
```

脚本4读取：

```text
项目\物料导入*.xls
项目\输出\物料回填\*_已匹配.xlsx
```

无需再次复制原始电气清单。

ET/ST规则：

- ET 为母件；
- 从一个 ET 开始，后续所有 ST 均属于该 ET，直到遇到下一个 ET；
- ST 子件先写，当前数量固定为1；
- 再逐条写入对应的京能物料；
- `京能物料号` 为 `客供件` 的记录直接过滤，不进入 ERP BOM；
- 同一 ET 母件下相同子件自动合并数量，ST 与京能物料号相同也参与合并；
- 合并完成后按首次出现顺序重新生成连续顺序号；
- 每个 ET 的顺序号从1重新开始连续递增。

`物料导入*.xls` 的 B列项目号是ERP生成范围的权威来源。脚本3结果中多余的项目编号会被忽略；物料导入表要求的项目编号若找不到脚本3结果，则停止生成并输出异常原因。

ERP模板：

```text
templates\ERP物料清单批量导入表.xls
```

脚本4通过 Microsoft Excel COM 复制并填写真实 Excel 97-2003 `.xls` 模板，不生成伪 `.xls`。

## 脚本5：项目一键处理

推荐用于日常处理。流程固定为：

```text
选择项目文件夹
    ↓
执行脚本1
    ↓
是否发现新物料？
    ├─ 是：停止，说明新物料数量，等待人工配置映射
    └─ 否
        ↓
执行脚本3
        ↓
是否全部匹配？
    ├─ 否：停止，说明异常数量/原因，不执行ERP
    └─ 是
        ↓
执行脚本4
        ↓
生成真实 .xls ERP导入表
```

任一步出现硬错误也立即停止，不继续执行后续步骤。重新运行脚本5会从脚本1重新检查，无需人工维护断点状态。

## 运行环境

推荐：Windows 10/11 + Python 3 + Microsoft Excel。

启动器会检查并尝试安装：

- `openpyxl`
- `xlrd`
- Windows 下的 `pywin32`

`.xls` 电气清单转换和最终ERP `.xls` 输出均需要本机安装 Microsoft Excel。

## BAT 编码

`run_tool.bat` 采用纯 ASCII、无 BOM、CRLF，仅负责启动 Python，避免中文 CMD 编码问题。
